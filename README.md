# Max Game

Браузерный платформер про сиба-ину, который собирает косточки.

**Играть:** https://maxshplmax.github.io/max-game/
**Обновления:** https://maxshplmax.github.io/max-game/changelog.html

---

## Недельный цикл

1. **Забрать изменения**
   ```
   git pull origin main
   ```

2. **Внести правку** — почти всегда это один из трёх файлов:

   | Что делаю | Что правлю |
   |---|---|
   | новый уровень, правка старого | `src/levels.js` |
   | внешний вид персонажа, предметов | `src/sprites.js` |
   | ощущение управления | `TUNING` в начале `src/scenes/GameScene.js` |

3. **Проверить локально** — двойной клик по `index.html`.
   Игра работает из файла, сервер не нужен. Потыкать: пройти уровень,
   умереть, перезапустить, проверить прыжки.

4. **Записать в changelog** — новая запись **сверху** в `changelog.js`.
   Это единственное место, где живёт номер версии.

5. **Выложить**
   ```
   deploy.bat
   ```
   Скрипт сам проверит раскладку файлов, подтянет изменения с GitHub,
   закоммитит и запушит.

6. **Проверить результат** — открыть сайт, убедиться что версия в шапке
   сменилась, и посмотреть, что пост появился в канале.

## Номера версий

| Что произошло | Как меняется номер |
|---|---|
| новый уровень, враг, механика | `0.5.0` → `0.6.0` |
| правка, баланс, мелочь | `0.6.0` → `0.6.1` |
| игра целиком готова | `1.0.0` |

Правило одно: если игроку есть что заметить — растёт средняя цифра.

## Устройство

```
index.html          главная: шапка, игра, подвал
changelog.html      страница обновлений
changelog.js        ИСТОЧНИК ПРАВДЫ: версия, история, текст поста
style.css           стили обеих страниц
og.png              карточка для ссылок в мессенджерах

src/
  main.js           запуск Phaser, размеры, масштабирование
  site.js           версия в шапке, рендер списка обновлений
  touch.js          экранные кнопки для телефона
  sprites.js        пиксель-арт: собака, косточка
  levels.js         карты уровней текстом
  save.js           прогресс в localStorage
  scenes/
    GameScene.js    физика, управление, сбор косточек, финиш

.github/
  workflows/telegram.yml     когда постить
  scripts/post-telegram.js   что постить
```

**Ключевой принцип:** контент отделён от кода. Уровни, спрайты и история
обновлений — это данные в текстовом виде. Менять их можно в блокноте,
не трогая логику.

## Автопост в Telegram

Срабатывает при пуше в `main`, если в нём менялся `changelog.js` **и**
верхняя версия отличается от той, что была до пуша. Правки кода без
новой записи канал не спамят.

Запустить вручную: `Actions` → «Пост в Telegram» → `Run workflow`.
Галочка *dry run* покажет текст, ничего не отправляя.

Секреты репозитория: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

## Что можно сделать дальше

- **Враги** — патрулирующие платформу, гибель при касании сбоку,
  победа при прыжке сверху
- **Второй уровень** — массив `LEVELS` уже поддерживает несколько,
  переход по флагу работает
- **Звук** — прыжок, подбор косточки, финиш
- **Экран выбора уровня** — с отметками пройденных из `save.js`
- **Таблица рекордов** — потребует бэкенда, Supabase на бесплатном тарифе
- **Свой домен** — вместо `github.io`
